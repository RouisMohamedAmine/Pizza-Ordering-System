🍕 Pizza Ordering System

My first C# Windows Forms project, developed to practice GUI development and apply C# fundamentals by building a simple pizza ordering application.

✨ Features

- Interactive Windows Forms interface
- Pizza ordering functionality
- Multiple forms for managing the ordering process

🛠️ Technologies

- C#
- .NET / Windows Forms
- Visual Studio

🎯 Purpose

This project was created as a learning experience to improve my understanding of C# and desktop application development.

🚀 Getting Started

1. Clone or download this repository.
2. Open "Pizza Project.sln" in Visual Studio.
3. Build and run the project.
